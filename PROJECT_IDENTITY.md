# Change Shockwave identity

- Mechanism signature: consensus identifies only direct service impacts; deterministic graph traversal derives the full blast radius and rollback order.
- Product metaphor: a controlled charge travelling through a dependency field.
- Narrative voice: terse change-control commands followed by measurable propagation facts.
- Visual grammar: irregular node field, hard lines, rectangular charge rail, no cards or dashboard grid.
- Interaction grammar: arrange topology, arm change, scan, inspect propagation, acknowledge.
- Evidence story: policy, change notice, and each service document are fetched and digest-bound; demo publishers are explicitly operator-controlled fixtures.
- README shape: preflight sheet, propagation law, field drill, released coordinates.
